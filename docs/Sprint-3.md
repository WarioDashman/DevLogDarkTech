## Sprint 3

in deze ben ik verder gaan werken aan de gespreksflow voor de bot zelf en een nieuwe toevoeging van onze project: een knop die dient als middel om de microfoon aan/uit te zetten. In deze log leg ik uit hoe het is gegaan, wat er goed ging, wat er beter kan, en wat ik ga doen in de laatste sprint van deze semester.

### DE KNOP

De vorige sprint kreeg ik als feedback dat ik deze sprint iets technisch moet gaan doen. Daarom heb ik als taak opgenomen om de knop werkend te maken voor de microfoon. Hierbij heb ik een lijst van taken ontvangen, die gedaan moeten worden om het te volbrengen. ik ben er recent mee begonnen en heb ondertussen een design gemaakt voor de behuizing van de knop. De afmetingen heb ik berekend op basis van de afmetingen van de knop zelf. Met behulp van fusion maakte ik beetje bij beetje de box gemaakt, waarin de knop wordt geplaatst in de gat van de box zelf.
